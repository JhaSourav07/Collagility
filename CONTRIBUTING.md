# Contributing to Collagility

Thank you for your interest in contributing to Collagility! We welcome contributions from developers of all skill levels.

---

## 🛠️ Development Setup

### 1. Prerequisites
- Node.js >= 22.0.0
- pnpm >= 9.0.0
- Git

### 2. Clone & Install
```bash
git clone https://github.com/JhaSourav07/Collagility.git
cd Collagility
pnpm install
```

### 3. Build & Test
```bash
# Build all monorepo packages
pnpm run build

# Run all unit and integration test suites
pnpm run test

# Run linter
pnpm run lint
```

---

## 🚀 Workflow Guidelines

1. **Fork the repo** and create your branch from `main`:
   `git checkout -b feature/my-new-feature`
2. **Make your changes** following TypeScript & ESLint guidelines.
3. **Write tests** covering your new features or bug fixes.
4. **Commit with descriptive messages**:
   `git commit -m "feat(adapters): add support for custom provider timeout"`
5. **Push to your fork** and submit a Pull Request.

---

## 💬 Community & Questions

Feel free to open an issue for bug reports, architectural discussions, or feature suggestions.

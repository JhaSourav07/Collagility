# Collagility v0.1.0-alpha.1

🚀 **First Public Alpha Release**

Collagility is an open-source multiplayer workspace for AI coding agents. Connect your local CLI tools (`agy`, `gemini`, `claude`) with collaborators and stream AI execution output token-by-token across every participant's terminal simultaneously.

---

## 🌟 Highlights

- **Multiplayer AI Collaboration**: Session owner hosts AI execution while collaborators participate in live chat and real-time stream observation.
- **Shared Terminal Sessions**: Token-by-token output and live progress logs stream across all connected terminals.
- **AI Adapter Framework**: Provider-agnostic adapter framework supporting `agy` (Antigravity), `gemini`, `claude`, and `codex`.
- **`agy` Integration**: Native support for Antigravity CLI print mode (`-p`) with live thinking and status rendering.
- **Workspace-Aware Execution**: AI tools execute commands directly inside the owner's project root workspace (`session.workspacePath`).
